# STRIDEN — Run • Ride • Conquer

Projeto inicial do aplicativo de corrida e ciclismo com disputa de territórios.

## O que está incluído
- `index.html`: protótipo web navegável da tela inicial.
- `assets/striden-icon.svg`: ícone vetorial original do projeto.
- `docs/PRODUCT_SPEC.md`: visão do produto e regras propostas.
- `docs/ROADMAP.md`: etapas de desenvolvimento.

## Como abrir
Extraia o ZIP e abra `index.html` em um navegador. Não precisa instalar dependências para visualizar o protótipo.

## Estado real do projeto
Este pacote é um **protótipo inicial**, não um aplicativo pronto para publicação. O mapa atual é ilustrativo; não usa mapas reais, GPS contínuo, contas, banco de dados ou sincronização entre usuários. Os botões demonstram a navegação e alguns fluxos.

## Próxima etapa técnica
Transformar o protótipo em aplicativo Android/iOS, integrar mapa real e localização em segundo plano com permissões explícitas, criar autenticação e backend, validar trajetos e implementar o motor de territórios com proteção contra fraude.
